# Fivefold v0.8 Beta → v0.8.5 Beta Reconciliation

This report compares the repository’s 2026-05-27 v0.8 Beta snapshot with the
pinned 2026-06-30 v0.8.5 export. Canonical files preserve source wording; this
report classifies product impact.

## Classification Key

- **Canonical v0.8.5**: rule text in the new export.
- **Implemented v2**: automated for `st-bozma-v0.8.5-v2`.
- **Historical v1**: retained only when resolving `st-bozma-mvp-v1`.
- **Adaptation**: approved deterministic solo behavior.
- **Deferred**: outside the fixed dungeon-crawler surface.
- **Formatting/source correction**: source wording or formatting without a
  current runtime behavior.

## Runtime-Relevant Decisions

### Version boundary

- **Implemented v2:** new runs default to `st-bozma-v0.8.5-v2`.
- **Historical v1:** existing `st-bozma-mvp-v1` snapshots keep their old object
  shape, legal commands, enemy definitions, RNG use, events, and resolution.
- **Safety:** unknown versions expose no legal commands and reject without state
  or RNG mutation. V2 snapshot decoding requires recorded health rolls and,
  during combat, explicit AP and used-action identities.

### Near/Far clarification

- **Implemented v2:** Far weapons target either rank. Near weapons require the
  wielder and target to be Near.
- **Implemented v2:** any Near occupant blocks Near weapons from Far allies;
  protection is positional, not a melee tag.
- **Implemented v2:** a Far weapon can target Barnabe through a living Raider;
  a Near weapon cannot.
- **Implemented v2:** when hostile Near is empty, the player may close distance
  without AP. V1’s automatic end-of-round collapse remains historical only.

### Solo rulings

- **Adaptation:** deterministic advantage uses the lower d100; disadvantage uses
  the higher.
- **Adaptation:** End Turn remains explicit at zero AP so an already-earned
  Maneuver can resolve before the enemy phase.
- **Adaptation:** Deathblow has no boss exception because a solo engine cannot
  make the source’s discretionary GM ruling.
- **Adaptation:** creatures of size 3 require hard Shove; creatures above size 5
  are deterministically unavailable as Shove targets.
- **Adaptation:** a critical Block counterattacks only when the equipped weapon
  can legally reach the attacker.
- **Adaptation:** Barnabe’s shared-GM-momentum cadence becomes alternating
  gather/Decode turns. His recurring 25 temporary HP is omitted for bounded
  solo balance.
