# MVP Product Direction

Status: user-approved for promotion preview on 2026-07-29.

## Decisions

- Single-player first.
- Seeded procedural St. Bozma dungeon first.
- Run-based roguelike progression; no permanent power carryover.
- Autosave active progress after accepted commands; death ends and archives the run.
- Read-only records preserve prior seed, class, depth, encounters, loot, and outcome.
- All five starting classes ship with viable level-1 kits.
- Initial run has eight rooms: fixed Monastery Grounds entry, six procedural middle rooms, fixed Resting Chamber finale.

## Rule Boundary

Keep deterministic, solo-applicable core rules exact when they fit the approved room/combat loop. Explicitly adapt GM rulings, group/ally mechanics, open-ended fiction, table pacing, procedural layout, and MVP death at 0 HP. Each automated feature needs a canonical citation or named adaptation in the spec.

## Deferred

Co-op, persistent campaigns, permanent metaprogression, specializations, broad perk automation, generalized procedural tooling, and full Fivefold automation.
