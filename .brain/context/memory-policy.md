# Memory Policy

## Always Preserve

- Pure deterministic game-engine boundary and event contract.
- Canonical rules versus explicit dungeon-crawler adaptation distinction.
- PocketBase per-request, server-only auth/privilege boundary.
- Obsidian + Bone official design decision.
- Seeded RNG, deterministic replay, and expected-version protection direction.
- Unresolved product decisions and their eventual Plan resolution.
- Non-obvious architecture, security, schema, rules, workflow, testing, and deployment changes.

## Avoid

- Temporary command output and routine formatting details.
- Speculation presented as a decision.
- Duplicate notes when an existing context or decision note can be updated.
- Brain runtime/session files as shared durable memory.
- Any summary that rewrites or replaces canonical rulebook text.
